# 実装仕様概要

## o3_spec1.mdの主要ポイント

### 1. トークナイザ拡張
- `<SEG>` トークンの追加（マスク出力位置を指示）
- オプション: `<VIS_SUM>`, `<MASK>`, `<DEPTH>` トークン

### 2. 視覚エンコーダ（Qwen2.5-VL ViT）
- 入力: 896×896ピクセル画像
- パッチサイズ: 14×14ピクセル → 64×64パッチ
- 隠れ次元: 1280
- 層数: 32層（前28層はローカル注意、7,15,23,31層はグローバル注意）
- 出力: (B, 1280, 64, 64) 特徴マップ

### 3. アダプタ層
- Conv1×1で1280→512次元に射影
- GroupNormで正規化
- DropPath（0.1）で正則化

### 4. SAM 2.1 マスクデコーダ
- Transformer次元: 512
- 出力マスク解像度: 256×256
- IoU予測ヘッド付き
- マルチマスク出力対応（K=1〜4）

### 5. 深度推定ヘッド（オプション）
- 入力: アダプタ出力 (512, 64, 64)
- 出力: 深度マップ (1, 256, 256)
- ConvTranspose2dで段階的にアップサンプル

### 6. LLM統合
- Embedding-as-Mask方式
- `<SEG>` トークン生成時にマスクデコーダを実行
- 隠れ状態（2048次元）→マスクプロンプト（512次元）に射影

### 7. 学習フェーズ
1. アダプタ＆デコーダWarm-up（5kステップ）
2. 結合ファインチューニング（Vision解凍）
3. 72B蒸留・スケールアップ（オプション）

### 8. 損失関数
- 言語損失（CrossEntropy）
- マスク損失（BCE + Dice）
- IoU損失（MSE）
- 深度損失（L1 + SiLog）
