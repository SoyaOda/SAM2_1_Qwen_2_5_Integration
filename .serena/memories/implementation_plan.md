# LISA改 段階的実装計画

## フェーズ1: 基盤構築（環境設定とベースモジュール）
1. **開発環境のセットアップ**
   - requirements.txt作成（PyTorch, transformers, timm等）
   - プロジェクト構造の作成（models/, utils/, configs/等）
   
2. **設定管理システム**
   - config.yamlによる設定管理
   - モデル設定クラスの実装

3. **トークナイザ拡張**
   - Qwen2.5-VLトークナイザのロードと特殊トークン追加（<SEG>等）
   - トークン埋め込みの拡張

## フェーズ2: 視覚エンコーダ実装
1. **Qwen2.5-VL ViTの統合**
   - 公式実装からViTコンポーネントを抽出・統合
   - パッチ埋め込み層の実装（896×896→64×64パッチ）
   - Transformer層の実装（32層、ローカル/グローバル注意）
   
2. **中間層フック機能**
   - Layer 8, 16, 24, 32の出力を取得するフック実装
   - マルチスケール特徴の保存機構

## フェーズ3: アダプタとSAMデコーダ
1. **アダプタ層**
   - Conv1×1による次元変換（1280→512）
   - GroupNormとDropPath実装
   
2. **SAM 2.1 マスクデコーダ**
   - PromptEncoderの統合
   - Transformerデコーダの実装
   - マスク予測ヘッド（Hypernetwork MLP）
   - IoU予測ヘッド
   - アップサンプリング層（64×64→256×256）

## フェーズ4: LLM統合
1. **Qwen2.5デコーダとの接続**
   - 画像要約トークン処理
   - <SEG>トークン生成時のフック実装
   - 隠れ状態→マスクプロンプト変換
   
2. **生成ループの改造**
   - 自動回帰生成中の特殊トークン処理
   - 複数マスク出力対応

## フェーズ5: 深度推定とマルチタスク学習
1. **深度推定ヘッド（オプション）**
   - ConvTranspose2dによるアップサンプリング
   - 深度マップ出力（256×256）
   
2. **損失関数とトレーニング**
   - マルチタスク損失の実装
   - 学習ループの実装
   - LoRA統合（オプション）

## フェーズ6: 評価とデモ
1. **評価スクリプト**
   - COCOでのセグメンテーション評価
   - IoU計算とmAP評価
   
2. **推論デモ**
   - Gradioベースのインタラクティブデモ
   - バッチ処理スクリプト

## 実装優先順位
1. まずフェーズ1-2で基盤を構築
2. フェーズ3でセグメンテーション機能を実装
3. フェーズ4でLLM統合を行い、基本的なLISA改を完成
4. フェーズ5-6は追加機能として順次実装
