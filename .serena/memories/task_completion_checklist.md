# タスク完了時のチェックリスト

## コード実装完了時

### 1. コード品質チェック
- [ ] Ruffでリントエラーがないことを確認
- [ ] Blackでフォーマットが整っていることを確認
- [ ] mypyで型チェックが通ることを確認

### 2. テスト
- [ ] ユニットテストを作成・実行
- [ ] 統合テストを実行（該当する場合）
- [ ] エッジケースをカバー

### 3. ドキュメント
- [ ] 関数・クラスのdocstringが記載されている
- [ ] 複雑なロジックにはインラインコメントを追加
- [ ] READMEを更新（必要に応じて）

### 4. パフォーマンス
- [ ] メモリ使用量が適切か確認
- [ ] 計算効率が最適化されているか確認

### 5. エラーハンドリング
- [ ] 適切なエラーメッセージを出力
- [ ] フォールバックコードを避け、明確なエラーを発生

### 6. Git
- [ ] 意味のある単位でコミット
- [ ] コミットメッセージが明確

## 重要な注意事項
- ダミーコードやフォールバック実装は避ける
- エラーは隠蔽せず、適切に表示してデバッグ情報を提供
- 解決したデバッグログは削除してコードをシンプルに保つ
- 公式実装（Qwen, SAM, HuggingFace, PyTorch）を積極的に参照
